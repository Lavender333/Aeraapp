How directory import works

1. The admin signs into Microsoft or Google.
2. AERA requests read-only access to names and work emails.
3. The admin selects people or groups.
4. AERA shows a preview and duplicate check.
5. The admin confirms before invitations are sent.

The buttons are ready in the website interface. The live connection still requires Microsoft Graph and Google Admin SDK OAuth credentials in the backend.
